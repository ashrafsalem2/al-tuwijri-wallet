================================================================
  SALES TRACKER — API CONTRACT (mock → real)
================================================================

The app currently reads the JSON files in /assets/api as if they were
live HTTP responses (see lib/services/api_service.dart). Each mock file
maps to one real endpoint below. When your backend is ready, flip the
flag `ApiService.useMock = false` and set `ApiService.baseUrl`.

Base URL (real):   https://api.yourbrand.com/v1
Auth:              Bearer <token>  (returned by POST /auth/login)

----------------------------------------------------------------
1) POST /auth/login
----------------------------------------------------------------
Request body:
  { "mobile": "+966501234567", "password": "••••••" }

Response  (mock file: assets/api/login.json):
  {
    "status": "success",
    "message": "Login successful",
    "token": "<jwt>",
    "expiresIn": 3600,
    "customerId": "CUST-1024"
  }

7) POST /rewards/{id}/redeem      (Authorization: Bearer <token>)
----------------------------------------------------------------
Deducts `cost` points and returns the new balance. The app currently
performs this locally on the mock; wire it here for the real backend.
  Response: { "status": "success", "data": { "balance": 2950 } }

================================================================
  HOW TO SWITCH TO THE REAL API
================================================================
  In lib/services/api_service.dart:
    static bool  useMock = false;
    static String baseUrl = "https://api.yourbrand.com/v1";
  The method signatures stay identical, so no screen code changes.
